A program (`main.ts`, Node 22) that writes one text to `/output/entry.txt`:
a deadpan one-star review of an everyday essential — sleep.

> Eight hours of sleep, and I wake up tired. Refund policy unclear.

Run it with:

```sh
node main.ts
```

It writes `entry.txt` to `/output`: UTF-8, one line, 65 characters,
byte-identical on every run. The review files a real complaint against
sleep in earnest — eight hours in, still tired — and turns in the last
few words, treating sleep like a product with no refund policy.
